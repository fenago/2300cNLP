# Puente Capital — Landing Page

Static landing page, deployed on Netlify.

- `index.html` — the page
- `assets/` — images, fonts, and JS (React + page runtime), all self-hosted
- `netlify.toml` — Netlify config (publishes the repo root, no build step)

Preview locally:

```bash
python3 -m http.server 8000
```
